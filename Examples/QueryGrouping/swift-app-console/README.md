# school-directory-statistics Swift console

Run `swift build` and `swift run TeaQLConsole`. The executable installs the
passive generated Runtime Module. The console target includes the SQLite provider
for application-owned composition; schema reconciliation remains explicit.

See [STANDARD_TELEMETRY.md](STANDARD_TELEMETRY.md) for the selected runtime's optional module, trusted activation variables and safe startup diagnostics.
